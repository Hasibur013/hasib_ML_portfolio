# Md. Hasibur Rahman — Machine Learning Engineer

Source for the recruiter-focused portfolio covering production computer vision, OCR, Edge AI, and applied ML research.

Live site: https://hasibur013.github.io/

Modeled on the same case-study layout as [rafiul_ML_portfolio](https://github.com/rafi0020/rafiul_ML_portfolio).

## What the portfolio demonstrates

- Production computer vision and OCR on Bondstein industry systems
- Bangla ANPR, container OCR, industrial safety, and banking surveillance case studies
- Personal ML, healthcare, and analytics projects
- Peer-reviewed research (IEEE SMC 2025, STI 2024)

## Technology

- React 18 and React Router
- Vite
- Custom responsive CSS
- GitHub Pages and GitHub Actions

## Local development

```bash
git clone https://github.com/Hasibur013/hasibur013.github.io.git
cd hasibur013.github.io
npm install
npm run dev
```

Build the production bundle with:

```bash
npm run build
```

Node.js 20 or newer is recommended.

## Content map

## Deployment

Pushes to `main` are built and deployed through `.github/workflows/deploy.yml`.

In the GitHub repo: **Settings → Pages → Source: GitHub Actions**.
